## 重要な共通ルールの要約

- 実装前に関連コード・設定・テストを調査し、既存設計を尊重して最小差分で変更する。
- TypeScript は型安全性を優先し、Python は型ヒントと明確な例外処理を使う。外部入力は境界で検証する。
- 不具合修正には回帰テストを追加し、lint、型チェック、テスト、ビルドを実行する。テスト削除やチェック無効化で回避しない。
- Secret・個人情報を出力しない。認証、認可、DB、公開 API は明確な根拠なしに変更しない。
- 実行していない検証を成功と報告せず、PR には変更内容、テスト結果、影響・リスク、未検証事項を記載する。
